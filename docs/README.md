## Criterios documentales

- **Confirmado**: práctica descrita por la academia.
- **Propuesto**: solución sugerida y todavía no aprobada formalmente.
- **Pendiente**: decisión que requiere validación.
- Cada incremento documenta objetivos, alcance, flujo, datos, permisos, UI, pruebas y cambios relevantes.
- Documentar en la misma rama que contiene el incremento; revisar mediante pull request.
- No incluir información personal real de menores ni credenciales en ejemplos.
- Los diagramas Mermaid deben mantenerse junto con el texto explicativo, no sustituirlo.
